No visitor tracking

Privacy

The generated site is static and makes no visitor-side network requests.

Application data

DistWitness processes public package-release, provenance, and vulnerability metadata. It does not create accounts, set cookies, collect analytics, add telemetry, fingerprint visitors, or provide contact forms.

Hosting

A static hosting provider may independently process ordinary access information under its own policies. DistWitness does not receive or store that information.

Watchlists and findings

A local watchlist remains in the repository where its operator places it. Publishing the generated site or repository makes the configured package names and generated findings public.

Evidence-backed release metadata changes. Review signals, not verdicts.
